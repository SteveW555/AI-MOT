# Convert Single-File React Project to Vite + TypeScript + React Stack

## Context
When presented with a single `index.html` file containing React JSX code (typically generated by AI tools using CDN-based React), convert it to a proper modern development setup with Vite, TypeScript, and React.

## Recognition Criteria
You're dealing with this scenario when you see:
- A file named `index.html` containing `import` statements and JSX code
- React components written directly in the HTML file
- References to `@/components/ui/*` (shadcn/ui patterns)
- `className` attributes with Tailwind CSS classes
- Code that won't run directly in a browser without build tools

## Step-by-Step Conversion Process

### 1. **Analyze the Existing Code**
- Read the `index.html` file completely
- Identify dependencies:
  - UI component libraries (shadcn/ui, Material-UI, etc.)
  - CSS frameworks (Tailwind CSS, plain CSS, etc.)
  - React features used (hooks, context, etc.)
  - Any special libraries imported

### 2. **Create Project Structure**
Create the following directory structure:
```
project-root/
├── src/
│   ├── components/
│   │   └── ui/              # For shadcn/ui or similar components
│   ├── lib/
│   │   └── utils.ts         # Utility functions (cn helper, etc.)
│   ├── App.tsx              # Main component (original code goes here)
│   ├── main.tsx             # React entry point
│   └── index.css            # Global styles
├── index.html               # Minimal HTML entry point
├── package.json
├── vite.config.ts
├── tsconfig.json
├── tsconfig.node.json
├── tailwind.config.js       # If Tailwind is used
└── postcss.config.js        # If Tailwind is used
```

### 3. **Create package.json**
```json
{
  "name": "project-name",
  "private": true,
  "version": "0.0.0",
  "type": "module",
  "scripts": {
    "dev": "vite",
    "build": "tsc && vite build",
    "preview": "vite preview"
  },
  "dependencies": {
    "react": "^18.3.1",
    "react-dom": "^18.3.1",
    "class-variance-authority": "^0.7.1",
    "clsx": "^2.1.1",
    "tailwind-merge": "^2.5.5"
  },
  "devDependencies": {
    "@types/react": "^18.3.18",
    "@types/react-dom": "^18.3.5",
    "@vitejs/plugin-react": "^4.3.4",
    "typescript": "^5.7.3",
    "vite": "^6.0.11",
    "tailwindcss": "^3.4.17",
    "postcss": "^8.4.49",
    "autoprefixer": "^10.4.20"
  }
}
```

**Note**: Adjust versions to latest stable. Use `^2.5.5` or similar for `tailwind-merge` if newer versions aren't available.

### 4. **Create Vite Configuration**

**vite.config.ts**:
```typescript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import path from 'path'

export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src'),
    },
  },
})
```

### 5. **Create TypeScript Configurations**

**tsconfig.json**:
```json
{
  "compilerOptions": {
    "target": "ES2020",
    "useDefineForClassFields": true,
    "lib": ["ES2020", "DOM", "DOM.Iterable"],
    "module": "ESNext",
    "skipLibCheck": true,
    "moduleResolution": "bundler",
    "allowImportingTsExtensions": true,
    "resolveJsonModule": true,
    "isolatedModules": true,
    "noEmit": true,
    "jsx": "react-jsx",
    "strict": true,
    "noUnusedLocals": true,
    "noUnusedParameters": true,
    "noFallthroughCasesInSwitch": true,
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  },
  "include": ["src"],
  "references": [{ "path": "./tsconfig.node.json" }]
}
```

**tsconfig.node.json**:
```json
{
  "compilerOptions": {
    "composite": true,
    "skipLibCheck": true,
    "module": "ESNext",
    "moduleResolution": "bundler",
    "allowSyntheticDefaultImports": true
  },
  "include": ["vite.config.ts"]
}
```

### 6. **Set Up Tailwind CSS** (if detected in original code)

**tailwind.config.js**:
```javascript
/** @type {import('tailwindcss').Config} */
export default {
  content: [
    "./index.html",
    "./src/**/*.{js,ts,jsx,tsx}",
  ],
  theme: {
    extend: {},
  },
  plugins: [],
}
```

**postcss.config.js**:
```javascript
export default {
  plugins: {
    tailwindcss: {},
    autoprefixer: {},
  },
}
```

**src/index.css**:
```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

### 7. **Create shadcn/ui Component Stubs**

If the original code uses `@/components/ui/*`, create minimal implementations:

**src/lib/utils.ts**:
```typescript
import { type ClassValue, clsx } from "clsx"
import { twMerge } from "tailwind-merge"

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}
```

**Component Templates** (create only what's used):

- **Button**: Basic button with variant support
- **Input**: Styled input field
- **Textarea**: Styled textarea
- **Label**: Form label
- **Card, CardHeader, CardTitle, CardDescription, CardContent**: Card components
- **Select, SelectTrigger, SelectValue, SelectContent, SelectItem**: Custom select dropdown

See the components created in this session for reference implementations.

### 8. **Move Original Code to src/App.tsx**

1. Copy all the React component code from `index.html`
2. Add proper TypeScript types:
   - Function parameters: `(field: string, value: string)`
   - Event handlers: `(e: React.ChangeEvent<HTMLInputElement>)`
   - Props interfaces where needed
3. Clean up formatting
4. Save as `src/App.tsx`
5. Add `export default ComponentName;` at the end

### 9. **Create Entry Points**

**index.html** (minimal):
```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Project Name</title>
  </head>
  <body>
    <div id="root"></div>
    <script type="module" src="/src/main.tsx"></script>
  </body>
</html>
```

**src/main.tsx**:
```typescript
import React from 'react'
import ReactDOM from 'react-dom/client'
import App from './App.tsx'
import './index.css'

ReactDOM.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>,
)
```

### 10. **Install Dependencies**

```bash
npm install
```

If you encounter version errors (e.g., `tailwind-merge@^2.7.0` not found):
- Edit package.json to use an available version (e.g., `^2.5.5`)
- Run `npm install` again

### 11. **Start Development Server**

```bash
npm run dev
```

Expected output:
```
VITE v6.x.x ready in XXXms

➜  Local:   http://localhost:5173/
```

### 12. **Clean Up**

- Delete any temporary files created during setup
- Verify the site loads correctly at `http://localhost:5173/`
- Test all functionality (forms, navigation, interactive elements)

## Tech Stack Summary

- React 18 with TypeScript

**Styling:**

**UI Components:**
- Custom minimal implementations of shadcn/ui patterns

**Utilities:**
- clsx + tailwind-merge for className management
- class-variance-authority for variant-based components

## Common Pitfalls to Avoid

1. **Don't skip directory creation** - Always create `src/components/ui` and `src/lib` first
2. **Check package versions** - Some versions may not exist, use stable alternatives
3. **Preserve exact functionality** - Don't simplify or change the original component logic
4. **TypeScript types** - Add proper types, especially for event handlers
5. **Path aliases** - Ensure `@/*` alias is configured in both vite.config.ts and tsconfig.json
6. **CSS order** - Import index.css in main.tsx, ensure Tailwind directives are first
