# AI MOT Landing Page

A responsive single-page landing page for AI MOT - an AI consultancy service.

## Features
- Responsive design with mobile-first approach
- Multi-step booking form
- Animated gear illustrations
- Modern gradient styling
- No build process required - just open in browser

## Usage
Simply open `index.html` in any modern web browser.

## Tech Stack
- React 18 (via CDN)
- Tailwind CSS (via CDN)
- Vanilla HTML/CSS/JavaScript
- No build tools required

## Future Development
To convert this to a full React project with backend:
1. Set up a React/Vite project
2. Install Tailwind CSS properly
3. Add Supabase for backend
4. Convert inline styles to separate CSS files
